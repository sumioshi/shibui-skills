## Quick Install

Install via Skills CLI:

```bash
npx skills add sumioshi/shibui-skills
```

Or copy the `skills/<skill-name>/SKILL.md` folder directly into:
- **Claude Code:** `.claude/skills/<skill-name>/SKILL.md`
- **Antigravity / Codex / Open Agent spec:** `.agents/skills/<skill-name>/SKILL.md`
- **Cursor / Windsurf:** `.cursor/rules/<skill-name>.mdc` or `.windsurfrules`
- **Lovable / Bolt.new / v0:** paste the `SKILL.md` body as your initial system/style context alongside your project prompt.
